# 価格に関する想定問答（FAQ）

商談やトライアル中にお客様から寄せられる、価格まわりの質問と回答例です。回答の数字は料金表・トークスクリプトと必ず揃えてください。

## 2026年7月1日の料金改定について

Q. Standard プランの価格は変わりますか？

A. 2026年7月1日から、Standard プランは月額 ¥30,000 から ¥35,000 に改定します。シフト自動作成 AI と API 連携を追加し、シフト作成から周辺システム連携まで一つのプランで進められるようになったためです。

Q. 既存顧客もすぐに新価格になりますか？

A. 2026年6月30日以前からご契約中のお客様は、2026年12月31日まで Standard の旧価格（月額 ¥30,000）を適用します。2027年1月1日以降は新価格を適用します。契約中の個別条件がある場合は、契約書の内容を優先します。

## 値引き・割引について

Q. 年間契約割引はいくらですか？

A. 2026年7月1日以降の年間契約割引は 10% OFF です。Standard プランの場合、月額換算で ¥31,500、年間 ¥378,000 です。

Q. 値引きはどこまで可能ですか？

A. 年間契約割引を含め、値引きの合計上限は 10% です。追加値引きとの併用はできません。安易な値引きは避け、まずシフト自動作成 AI と API 連携を含む価値訴求を優先してください。

Q. 複数拠点だと安くなりますか？

A. 5 拠点以上の場合は個別にご相談ください。ただし、ボリュームディスカウントを含む値引きの合計上限は 10% です。年間契約割引との重複適用はできません。

## 他社比較について

Q. 他社サービスより高くないですか？

A. 機能の網羅性で優位性があります。打刻・シフト・残業管理に加えて、シフト自動作成 AI と API 連携が 1 つにまとまっています。複数ツールの併用コストや運用の手間を含めた総コストで比較いただくと割安になるケースが多いです。

## 契約・支払いについて

Q. 月払いと年払いはどちらが得ですか？

A. 年払いは 10% OFF になるため、継続利用が前提であれば年払いがお得です。ただし中途解約時の返金はできません。

Q. 初期費用はかかりますか？

A. 基本プランの初期費用は ¥0 です。オンボーディング支援（初回 ¥50,000）をご利用の場合のみ別途かかります。
